🎨 WordVault Icon Generator

Generate PWA icons for your WordVault app

Instructions:

  1. Click each download button to save the icons
  2. Rename the downloaded files:
    • First download → pwa-192x192.png
    • Second download → pwa-512x512.png
    • Third download → apple-touch-icon.png
  3. Place all three files in the public/ folder
  4. Run npm run build to rebuild with icons
